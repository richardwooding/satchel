# satchel

Croc-style sharing from your system tray. Copy something, pick **Share
clipboard**, and read out the code phrase (`lion-42-maple`); the other side
types it into their satchel — or into a web page, no install needed — and it
arrives, end-to-end encrypted, through a relay that cannot read it. Pair a
device once and send to it by name after that.

Built on [parley](https://github.com/richardwooding/parley). Work in
progress.
